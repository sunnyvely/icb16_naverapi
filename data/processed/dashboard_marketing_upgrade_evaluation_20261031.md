# 브랜드 톤앤매너·보고용 UI/UX 평가

## 평가 방법

- 대상: Streamlit `app.py`
- 평가일: 2026-10-31
- 자료: 브랜드별 뉴스 표본, BoW/TF-IDF 결과, NAVER 검색어트렌드 (2022-01~2026-09)
- 점수: 항목별 5점. **4점 이상 도달**, 아래 기준 미만은 개선 대상으로 판정.
- 기능 확인: Streamlit AppTest에서 초기 상태와 브랜드별 단독 선택 상태를 실행해 예외가 없는지 확인하고, 보고서 Markdown 다운로드 컨트롤을 확인.
- 시각 구조 확인은 앱 구성과 렌더링 요소에 기반합니다. 모바일 실기기별 픽셀 단위 검수는 배포 후 수행해야 합니다.

## 적용한 개선

1. **브랜드 시각 렌즈:** 유니클로는 절제된 레드와 기능·일상 카피, 스파오는 웜 오렌지와 협업·팬덤 카피, 탑텐은 짙은 그린과 실용·베이식 카피를 사용합니다. 이는 기사에서 관찰한 마케팅 렌즈를 대시보드 UI에 반영한 것으로 공식 브랜드 아이덴티티를 대체하지 않습니다.
2. **보고용 한 장 요약:** 최신월 상대지수, MoM·YoY 포인트 차, 경쟁 순위, 주제 믹스, 반복 메시지, 다음 액션, 근거 기사 링크를 미리 보고 Markdown으로 내려받을 수 있습니다.
3. **시각 위계:** 집중 브랜드 선을 굵게 강조하고 경쟁 브랜드는 보조 시각 강도로 낮춰 비교 초점을 분명히 했습니다. 차트는 색 외에 범례·레이블을 제공합니다.
4. **해석 신뢰:** 지수 차이를 성장률로 오해하지 않도록 `pt`로 표기하며, 뉴스 표본과 사전 기반 내러티브 분석의 범위·한계를 화면 및 보고서에 반복 표시합니다.
5. **보고 흐름:** `보고 요약 → 뉴스·언어 신호 → 검색·세그먼트 → 키워드 탐색 → UI/UX 평가` 순서로 보고와 탐색을 분리했습니다.

## 최종 판정

**6개 평가 항목 모두 4점 이상으로 도달**했습니다. 반복 사용할 수 있는 보고 요약 출력과 브랜드별 시각 톤을 구현했고, 검색 지수와 규칙 기반 기사 언어 신호의 해석 한계를 함께 밝혔습니다. 다만 작은 화면에서의 실제 가독성은 배포 후 휴대폰·태블릿에서 확인할 것을 권장합니다.

추가로 월별 뉴스 메시지 믹스나 캠페인 전후 효과를 보고하려면 뉴스 표본을 정기적으로 누적하고, 캠페인 집행일·성과 데이터와 별도로 연결해야 합니다. 현재 뉴스 검색 표본만으로 전체 미디어 점유율이나 캠페인 인과효과를 말할 수 없습니다.
